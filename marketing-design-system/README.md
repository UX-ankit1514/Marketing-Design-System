# Marketing Design System — project archive

Everything that was used to build **Arnifi Marketing Studio** (the poster editor from the *Arnifi Marketing Design System* PRD), arranged so you can find things again later. Snapshot of 22 Oct 2026, taken after commit `d6c0ca8` on https://github.com/UX-ankit1514/Marketing-Design-System.

> The live, working copy of the app is the folder **above** this one (`arnifi-marketing-studio/`). This folder is a tidy, self-contained reference copy. Nothing here is needed for the app to run.

## Read in this order

| Folder | What is in it | Open this first |
|---|---|---|
| `01-requirements/` | The PRD you pasted (original `.rtf` + plain-text copy), the implementation plan that was approved, and a PRD-to-code traceability sheet | `decisions-and-assumptions.md` |
| `02-design-sources/` | Everything the design came from: Figma file details and all 20 reference renders, the Arnifi design-system snapshot used for the app's own UI, brand assets | `figma/README.md` |
| `03-app/` | **The complete, runnable project**: source code, 20 templates, assets, import scripts, tests, configs | `03-app/README.md` |
| `04-documentation/` | Every document in one place: build log, data model, Figma import notes, template inventory, test report, known limitations, demo checklist | `BUILD-LOG.md` |
| `05-evidence/` | Proof it works: screenshots of the app, pixel-match results against Figma | `parity-results.json` |

## "I want to…" — where to look

| I want to… | Go to |
|---|---|
| Run the app | `03-app/README.md` → *Start it* (needs Node 22 and `npm install`) |
| Understand what was asked | `01-requirements/Marketing-PRD-readable.txt`, then `decisions-and-assumptions.md` |
| See which PRD item is built where, and which test covers it | `01-requirements/decisions-and-assumptions.md` (traceability table) |
| See which Figma frames became templates, and why others did not | `04-documentation/template-inventory.md` and `02-design-sources/figma/` |
| Compare a template with its Figma original | `02-design-sources/figma/reference-renders/<template-id>.png` vs `03-app/public/thumbs/<template-id>.webp` |
| Add or fix a template | `04-documentation/figma-import.md`, then `03-app/scripts/figma/` |
| Understand the data format | `04-documentation/template-data-model.md` and `03-app/src/types/` |
| Change how the editor behaves | `03-app/src/features/editor/` (UI), `03-app/src/lib/canvas/` (drawing) |
| Find out how it was built, what went wrong and how it was fixed | `04-documentation/BUILD-LOG.md` |
| Know what is not finished | `04-documentation/known-limitations.md` |
| Demo it to stakeholders | `04-documentation/demo-checklist.md` |
| Check test results | `04-documentation/test-report.md`, `05-evidence/` |
| Check the brand colours/fonts the UI follows | `02-design-sources/design-system/` |
| Find the logo files | `02-design-sources/brand-assets/` |

## Quick start (from this archive)

```bash
export PATH="/opt/homebrew/opt/node@22/bin:$PATH"   # this Mac's default Homebrew node is broken
cd 03-app
npm install
npm run dev -- --port 5180
```

## What was left out of the copy (and why)

`node_modules/` and `dist/` (rebuilt by `npm install` / `npm run build`), `test-results/` (regenerated by the tests) and `.git/` (the history lives on GitHub). Nothing else was left out: all 20 templates, every photo and graphic, the raw Figma extractions (`03-app/inventory/raw/`), reference renders, parity renders, and all scripts are here.

## Size note

This folder is about 125 MB because it contains a full copy of the project's assets next to the app. If you ever commit it to Git, it roughly doubles the repository; the parent project already holds everything needed to rebuild.
