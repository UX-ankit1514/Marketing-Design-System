# Brand assets

- `arnifi-logo.svg` — Arnifi primary logo, blue, vector (107×30). Copied from the existing `arnifi-explainer/brand/` folder in `~/Desktop/files`.
- `arnifi-logo-white.png` — white logo, 449×122 PNG. This is the 3× export of the footer/header logo from the *One Partner* story template in Figma (Figma's SVG export was unreliable, see `../../04-documentation/figma-import.md`).

Both are offered in the editor under **Add to design → Arnifi logo (blue/white)**. Poster templates carry their own logo picture exported from their Figma frame (see `03-app/public/template-assets/<template-id>/`).

Fonts are not stored here: **Inter** and **Lora** are installed from npm (`@fontsource/inter`, `@fontsource/lora`, SIL Open Font License) and bundled into the app build.
